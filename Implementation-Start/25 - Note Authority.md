# Note Authority

For implementation decisions, precedence is:

1. Live verified source behavior and tests.
2. [[01 - Canonical Ingestion Architecture]] for current runtime structure.
3. Nasdaq DROP protocol/message notes for source payload meaning.
4. Older architecture/design notes for historical context only when they do not conflict with the current boundary.

If an older note conflicts with the canonical boundary, update it or mark the conflicting section superseded rather than silently following it.
