# Runbook — Bad Rule Rollback

1. Disable promotion of the affected rule version.
2. Activate the last known-good immutable version.
3. Publish `RulePackChanged`.
4. Verify every silo reports the expected active version.
5. Mark alerts generated by the bad interval for re-evaluation.
6. Replay the affected sequence/time range in replay cluster.
7. Record root cause and add regression fixture.
