# Import into Obsidian

This folder is already Obsidian-ready.

## Add it to an existing vault

1. Unzip the package.
2. Copy the `Market-Surveillance` folder into your vault's `Projects/` folder (or anywhere inside the vault).
3. Open `Market-Surveillance/00 - Project Home.md`.
4. Open Obsidian **Graph view**. Wikilinks already connect cases → families → detectors → related cases.

## Use it as its own vault

You can also choose **Open folder as vault** and select the `Market-Surveillance` folder itself.

## Important taxonomy note

The 540 case names/descriptions come from the supplied trading-surveillance catalog. Family assignments, detector links, and related-case similarity links are an initial graph seed for organization and implementation planning; they can be refined as the rules are modeled.
