# Tutorial Overview

## Objective
Build a small .NET 10 application that makes Orleans concepts visible and practical.

The tutorial combines:
- Orleans grains,
- grain persistence,
- concurrency concepts,
- Orleans dashboard,
- .NET Aspire,
- dynamic rules execution.

## Learning style
Introduce one concept at a time, run it, observe it, then add the next layer.
