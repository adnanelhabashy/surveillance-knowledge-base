# Use Project-Scoped Notes First

## Decision
Keep Orleans learning notes inside the `Orleans-Rules-learning` project until a concept becomes genuinely reusable across multiple projects.

## Why
This prevents a new vault from becoming a collection of disconnected generic notes too early.

## Promotion rule
When another project needs the same concept, move or rewrite the reusable concept in `30 Resources`, and keep a project-specific note linking to it.
