# .NET Aspire with Orleans

Aspire helps orchestrate and observe a distributed .NET application during development.

In our tutorial it can be used to start and view pieces such as:
- Orleans silo/host,
- web/API/dispatcher,
- storage dependencies,
- dashboard/telemetry integrations.

Important distinction:
Aspire is not Orleans itself. Orleans handles the virtual actor runtime; Aspire helps compose and observe the distributed application.
