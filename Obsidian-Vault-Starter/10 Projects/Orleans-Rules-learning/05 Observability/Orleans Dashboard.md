# Orleans Dashboard

The dashboard is useful while learning because it makes the otherwise abstract cluster visible.

Use it to understand:
- silos,
- grain activations,
- request activity,
- cluster behavior,
- basic performance signals.

The dashboard is a learning/diagnostic aid; production observability should still be designed intentionally.
