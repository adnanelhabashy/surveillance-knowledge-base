# Vault Home

This vault is organized around **Projects**, with reusable knowledge kept separate.

## Active projects
- [[10 Projects/Orleans-Rules-learning/00 Project Hub|Orleans-Rules-learning]]

## Structure
- `00 Home` — entry points and global maps of content.
- `10 Projects` — one folder per active project.
- `20 Areas` — long-running responsibilities that are not projects.
- `30 Resources` — reusable references, patterns, snippets, and research.
- `90 Archive` — completed or inactive material.
- `_templates` — note templates.

## Rule of thumb
If a note only makes sense inside one project, keep it in that project's folder.
If you find yourself linking to the same idea from multiple projects, promote that note into `30 Resources`.
